# 3x-ui Manager

The app is intentionally Ingress-only. It does not publish a host port.

The API token is read from `/data/options.json` and is never returned by any frontend endpoint.

For 3x-ui 3.9.0, the generator creates the inbound with `/panel/api/inbounds/add`, then creates/attaches the client with `/panel/api/clients/add`. X25519 keys are generated by `/panel/api/server/getNewX25519Cert`.
